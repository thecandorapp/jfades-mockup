# JFADES STUDIOS — Website Concept

Modern website concept for [@jfadesldn](https://www.instagram.com/jfadesldn/) — JFADES STUDIOS, premium men's grooming studio in Ilford, London.

## Real data used
All services, prices, and review themes pulled from the live Booksy listing:
- Address: 42A Woodford Avenue, Ilford IG2 6XQ
- Booksy rating: 4.9 / 665+ reviews
- Head Barber: José
- Real service menu and prices (Standard, VIP, Luxury CEO Treatment, Braiding, etc.)

## Design rationale
Premium, dark, masculine aesthetic — gold accents on near-black, serif display type, generous whitespace. Built to match the price point (£40–£150) and signal luxury barbering, not high-street.

## Caveats before going live
- **All imagery is pulled from the Booksy CDN as placeholders.** Replace with owned brand photography before launch.
- **No real booking integration.** All "Book Now" buttons are visual only — would link to Booksy or a custom booking system in production.
- **Founder copy is generic.** Replace with José's actual voice and story.
- **Hours show "By appointment"** — replace with real opening hours.

## Tech
Single self-contained HTML file. Loads Inter + Playfair Display from Google Fonts and Tabler Icons from jsDelivr CDN. No build step, no dependencies beyond fonts.
